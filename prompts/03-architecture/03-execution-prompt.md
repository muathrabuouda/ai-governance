# Architectural Plan Execution Prompt

**Software Architecture** · "Architectural Decisions Cannot Be Delegated" · Plan Execution

```text
Execute the approved architectural plan step-by-step.
Run the tests after each step. Do not modify documentation files or ADRs unless explicitly asked.
If you need to deviate from the approved plan, stop immediately and ask for guidance.
At the end, summarize the changes made, the acceptance criteria satisfied, and any items remaining.
```
