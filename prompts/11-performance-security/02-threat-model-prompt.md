# STRIDE Threat Modeling Prompt

**Performance & Security** · "Change Safely, Measure, Then Deploy" · Threat Modeling

```text
Perform a STRIDE security threat analysis on Story #[ ]:
For each of the six STRIDE categories:
1. Spoofing: Identity falsification risks.
2. Tampering: Data tampering or payload alteration.
3. Repudiation: Denying actions occurred.
4. Information Disclosure: PII or credential leaks in logs or responses.
5. Denial of Service: Resource exhaustion or unthrottled endpoints.
6. Elevation of Privilege: Unauthorized role or boundary crossing.
For each threat, specify the proposed mitigation control and the automated test verifying it.
```
