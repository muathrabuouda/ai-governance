# Regression Protection Prompt

**Testing & Verification** · "Mutation Testing and Property Invariants" · Defect Reproduction

```text
For the reported defect [Bug Description]:
1. Write an automated test that reproduces the defect and fails on current code.
2. Apply the minimal fix to resolve the defect.
3. Verify the reproduction test passes.
4. Commit the test alongside the fix as permanent regression protection.
```
