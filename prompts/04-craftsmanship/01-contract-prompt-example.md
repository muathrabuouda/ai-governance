# Contract-First Prompt — Example

**Code Craftsmanship** · "Generation, Review, and Localization" · Contract-First Development

```text
Read the rules file, the specification, and the domain model.
We are working on Story #4 only: Cancel Appointment.
Write the CONTRACT ONLY: the types, function signature, all possible outcomes including domain errors, and the external dependencies passed into the function.
Do not write the implementation. Make the function body throw "not implemented".
Then stop, and identify any acceptance criterion not represented in the contract.
```
