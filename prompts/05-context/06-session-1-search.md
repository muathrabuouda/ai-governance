# Multi-Session Protocol: Session 1 — Search & Discovery

**Context Engineering** · "The Minimum Correct Context Suffices" · Session 1: Exploration

```text
Session 1 of 3: Exploration & Search.
Task: Investigate [Feature / Bug]. Do not write any code and do not plan the fix yet.
Search the codebase, identify affected files, trace data flows, and report your findings.
End your response with a concise summary ready to be passed into Session 2.
```
